## Rules About This Structure

- **Never** create `src/components/` at the top level. Reusable UI lives in `src/shared/ui/`. Module-specific UI lives in `src/modules/{module}/ui/`.
- **Never** put business logic in `src/app/`. Pages render layouts and module UI components.
- A module **may** import from `src/shared/`. A module **must not** import from another module's internals.
- If two modules need the same type/util, it goes in `src/shared/`.
